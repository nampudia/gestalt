Screentest

Where you lost them

Stretches where the share of people watching the screen stayed well under this film's own average for a minute or more, worst first.

    Did the beats land?

    Tag the moments where you expect a reaction. A beat lands when at least half the people in the room react within a few seconds.

    Session file format and how the numbers are computed

    Load one JSON file per viewer. Each file is a set of once-per-second arrays that start when the film starts. The capture script that ships with this dashboard writes this format and never saves video.

    {
  "viewer_id": "v07",
  "film": "Landlord, cut 3",
  "dt": 1,
  "face":      [1, 1, 1, 0, ...],   // 1 when a face was found in frame
  "attention": [1, 1, 0, 0, ...],   // 1 when the head is turned toward the screen
  "motion":    [0.04, 0.05, ...],   // head movement, relative to face size
  "smile":     [0.02, 0.61, ...]    // 0 to 1, relative to the viewer's resting face
}

    Watching is the share of people in the room whose head is toward the screen. In the room is the share of viewers whose face is still being found. In sync takes each viewer's combined smile and movement signal over a rolling minute and correlates it with everyone else's: near 0 means people are reacting on their own, higher means the film is driving them together. Laugh beats count a smile above 0.5 within 5 seconds, scare beats count a movement spike three deviations above that viewer's norm within 3 seconds, and hold beats count eyes on screen with unusually little movement for the next 20 seconds.
